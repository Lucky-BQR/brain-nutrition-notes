# 脑营养学笔记

「脑营养学」两天线下课程（主讲：钱笛，2025 年 11 月 20–21 日）的完整整理，做成了一个可以直接在浏览器里阅读的网站。

**在线阅读：** https://lucky-bqr.github.io/brain-nutrition-notes/

| 页面 | 内容 |
|---|---|
| 课程笔记 | 按主题整理的 32 章知识点，含示意图和录音出处 |
| 实用建议清单 | 补剂速查表、按问题查、饮食与生活方式、自查与禁忌 |
| 每段录音摘要 | 6 段录音的时间线和要点 |
| 可读版文字稿 | 第一天、第二天的整理版全文 |

每个页面都有对应的 PDF（带书签目录），在首页底部或各页标题下方下载。网站支持全站搜索（Ctrl K）、深色模式和手机阅读。

> 内容整理自课堂录音，反映的是主讲人的观点和经验，不是医疗建议。标"存疑"或 ⚠ 的剂量和名称来自语音识别，使用前请对照课件或回听。同学姓名已去掉。

## 重新生成

```bash
npm install
npm run build   # content/*.md → 各 HTML 页面和 search.json
npm run pdf     # 用本机 Chrome 打印 pdf/*.pdf（可用环境变量 CHROME 指定路径）
```

- `content/`：Markdown 原文
- `scripts/build.mjs`：生成页面、目录和搜索索引；`scripts/figures.mjs`：课程示意图；`scripts/sanitize.mjs`：发布前去掉同学姓名和私人链接
- `assets/`：样式和脚本，没有外部依赖（不加载任何 CDN 或网络字体）
